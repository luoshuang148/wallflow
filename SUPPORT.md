# 获取帮助 / Getting help

欢迎中文或英文。无需了解 Swift 或 GitHub 开发流程，也可以反馈使用体验。

| 你的需求 | 去哪里 |
| --- | --- |
| 安装、导入和工具配置 | [使用指南](docs/USER_GUIDE.md) |
| 使用中不清楚怎么操作 | [使用求助](https://github.com/luoshuang148/wallnamic/issues/new?template=question.yml) |
| 软件行为与预期不符 | [问题反馈](https://github.com/luoshuang148/wallnamic/issues/new?template=bug_report.yml) |
| 希望增加或改进功能 | [功能建议](https://github.com/luoshuang148/wallnamic/issues/new?template=feature_request.yml) |
| 贡献代码、翻译或文档 | [贡献指南](CONTRIBUTING.md) |
| 安全漏洞或会话泄露 | [私密安全报告](https://github.com/luoshuang148/wallnamic/security/advisories/new) |

提交前请搜索[现有问题](https://github.com/luoshuang148/wallnamic/issues)并查看[已知问题](docs/KNOWN_ISSUES.md)。附上 Wallnamic 版本、macOS 版本、芯片类型、显示器数量，以及已经尝试的操作。维护者没有承诺固定响应时限；清晰的复现步骤有助于定位。

截图和日志请先脱敏，不要公开密码、验证码、Cookie、令牌、Steam 会话文件、完整状态文件或无权分享的壁纸。

## English

Questions and contributions are welcome in Chinese or English. You do not need Swift experience to report a problem or suggest an improvement.

| Need | Where to go |
| --- | --- |
| Installation, imports, and tool setup | [User guide](docs/USER_GUIDE.en.md) |
| A usage question | [Ask for help](https://github.com/luoshuang148/wallnamic/issues/new?template=question.yml) |
| Unexpected app behavior | [Report a bug](https://github.com/luoshuang148/wallnamic/issues/new?template=bug_report.yml) |
| A new feature or improvement | [Suggest a feature](https://github.com/luoshuang148/wallnamic/issues/new?template=feature_request.yml) |
| Code, translations, or documentation | [Contributing guide](CONTRIBUTING.md) |
| A security vulnerability | [Private report](https://github.com/luoshuang148/wallnamic/security/advisories/new) |

Search [existing issues](https://github.com/luoshuang148/wallnamic/issues) and check [known issues](docs/KNOWN_ISSUES.md) first. Include your Wallnamic and macOS versions, chip, display count, and what you already tried. No fixed response time is promised.

Sanitize screenshots and logs. Do not publish passwords, verification codes, cookies, tokens, Steam session files, complete state files, or wallpapers you lack permission to share.
